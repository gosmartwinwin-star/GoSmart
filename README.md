# GoSmart 🚖

## Akıllı Taksi Eşleştirme Platformu

GoSmart yalnızca bir taksi çağırma uygulaması değildir.

GoSmart;

- ticari taksilerin boş dönüşlerini azaltmayı,
- yolcuların daha ekonomik ulaşım sağlamasını,
- taksicilerin gelirini artırmayı,
- şehir içi ulaşım kaynaklarının daha verimli kullanılmasını

amaçlayan akıllı bir eşleştirme platformudur.

---

## Projenin Vizyonu

GoSmart, aynı yöne giden yolcular ile uygun taksileri akıllı algoritmalar kullanarak eşleştirir.

Bu sayede:

- Daha az boş kilometre
- Daha düşük ulaşım maliyeti
- Daha yüksek taksici geliri
- Daha verimli şehir içi ulaşım

hedeflenmektedir.
